# Outpatient-Clinics-Performance-Analysis
An end-to-end data engineering and analytics project for outpatient clinics using Python, SQL, and Power BI
كما وعدتكم في منشوري الأخير، يسعدني اليوم مشاركة تفاصيل مشروعي المتكامل (End-to-End) لقياس وتحليل أداء العيادات الخارجية (Outpatient Clinics Performance).

في هذا المشروع، لم أكتفِ بتصميم واجهة العرض، بل قمت ببناء دورة حياة البيانات بالكامل ابتداءً من الصفر لمحاكاة بيئات العمل التقنية الحقيقية في القطاع الصحي(اسحب الصور لليسار لرؤية كواليس بناء المشروع 👈).مر المشروع بثلاث مراحل رئيسية:

1️⃣ هندسة البيانات (Data Engineering): استخدمت لغة Python (تحديداً مكتبتي NumPy و SQLAlchemy) لتوليد وتنظيف وتطبيق قواعد العمل (Business Logic) على بيانات تحاكي سير العمل اليومي، ثم أتمتة تصديرها إلى SQL Server.
2️⃣ نمذجة البيانات (Data Modeling): قمت بتصميم نموذج بيانات علائقي داخل Power BI، يربط جدول المواعيد (Appointments_Fact) بجداول الأطباء، المرضى، والأقسام (Dimension Tables) لضمان كفاءة التحليل.
3️⃣ التحليل وتصور البيانات (Data Visualization): صممت لوحة قياس تنفيذية تفاعلية مزودة بشريط تنقل جانبي يسهل الوصول لصفحات النظام (Home, Doctors, Analytics, Settings).

تساعد هذه اللوحة القيادات التشغيلية على المراقبة اللحظية لـ:
🔹 إجمالي حجم العمل: 5 آلاف موعد لـ 989 مريضاً.
🔹 معدلات الهدر التشغيلي: تتبع نسبة عدم الحضور (No-Show Rate) والتي بلغت 15.66%، وتوزيعها مقارنة بالحضور والإلغاء.
🔹 الكفاءة التشغيلية: قياس متوسط وقت الانتظار الفعلي (32 دقيقة) وتتبعه عبر مختلف الأقسام الطبية.
🔹 أداء الكادر الطبي: تقييم متوسط التقييم الفردي للأطباء وحجم المواعيد المنجزة لكل طبيب.
